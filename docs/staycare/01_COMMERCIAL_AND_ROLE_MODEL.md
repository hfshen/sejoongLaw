# Sejoong StayCare 계약·수익·역할 모델

## 1. 권장 계약 구조

### 계약 A: 가입자 또는 고용주 ↔ 법무법인 세중

세중은 다음 항목을 포함한 멤버십 또는 운영지원 서비스 계약을 체결한다.

- 플랫폼 이용권
- 일반 안내 및 일정관리
- 정해진 범위의 상담접수
- 생활지원 요청 접수
- 전문기관 연결
- 계약서에 명시된 정기 체크인
- 서비스 제공내역 확인

법률사건, 행정대행, 노무사건, 보험·금융상품 등은 멤버십 포함 여부와 별도 계약 여부를 명확히 구분한다.

### 계약 B: 법무법인 세중 ↔ 운영사

운영사는 세중의 수탁자로서 다음을 수행한다.

- 플랫폼 구축 및 유지보수
- 회원 온보딩 운영
- 일반 문의와 생활지원 접수
- 체크리스트·업무·기한관리
- 다국어 고객지원 조정
- 파트너 배정 및 처리상태 추적
- 월간 운영보고
- 장애·보안·개인정보 사고 대응 지원

운영사의 보수는 법률사건 수임료와 연결하지 않고 독립적으로 산정한다.

### 계약 C: 세중 또는 운영사 ↔ 전문 파트너

업무 성격에 따라 별도 계약을 사용한다.

- 행정사·출입국 민원 대행기관
- 공인노무사
- 통역·번역사업자
- 통신사 또는 공식 판매점
- 보험사 또는 등록된 모집채널
- 병원·검진기관
- 숙소·기숙사 운영사
- 긴급출동·이동지원 업체

## 2. 역할분리표

| 업무 | 세중 | 운영사 | 전문 파트너 | 고용주 | 근로자 |
|---|---|---|---|---|---|
| 상품·약관·대외 책임 | A | C | I | I | I |
| 플랫폼 개발 | C | A/R | I | I | I |
| 회원등록·일정관리 | A | R | C | C | R |
| 일반 생활문의 | C | A/R | C | I | R |
| 법률판단·법률사건 | A/R | I | C | C | C |
| 출입국 서류대행 | C | I/C | A/R | C | R |
| 노무·임금·산재 전문업무 | C | I/C | A/R | C | C |
| 통신·숙소·병원 조정 | A | R | R | C | C |
| 구독 청구·환불 | A/R | C | I | C | C |
| 운영비 청구 | C | A/R | I | I | I |
| 개인정보 정책 | A | R | C | C | C |
| 감사로그·증빙 | A | R | C | I | I |

A: Accountable, R: Responsible, C: Consulted, I: Informed

## 3. 수익모델

### 세중의 매출

- 월간 멤버십
- 연간 멤버십
- 고용주 단체계약
- 초기 온보딩 패키지
- 별도 법률상담 또는 사건 수임
- 별도 행정·노무 전문서비스
- 적법한 제휴서비스 매출

### 운영사의 매출

- 초기 제품 구축비
- 월 기본 운영비
- 활성회원당 운영비
- 다국어 상담 운영비
- 현장방문·동행 실비
- 시스템 유지보수비
- 고객사별 커스터마이징비
- 리포트·데이터 마이그레이션 비용
- SLA 또는 야간대응 옵션비

### 권장 운영비 산식

```text
월 운영비 = 기본 PM 비용
          + 활성회원 수 × 회원당 운영단가
          + 실제 통역/현장/긴급출동 비용
          + 승인된 제3자 실비
```

운영비는 사건 수임 여부, 승소 여부, 비자 허가 여부에 연동하지 않는다.

## 4. 파일럿 가격 가정

가격은 계약 전제와 지원범위가 확정된 뒤 세중이 최종 결정한다. 제품에는 가격을 환경설정으로 관리하고 코드에 고정하지 않는다.

### 근로자 직접가입 예시

| 플랜 | 월 | 연 | 예시 범위 |
|---|---:|---:|---|
| Basic | 39,000원 | 390,000원 | 앱, 문서함, 일정, 일반 안내 |
| Care | 79,000원 | 790,000원 | Basic + 정기 체크인 + 생활지원 티켓 |
| Care Plus | 99,000원 | 990,000원 | Care + 확대된 지원시간과 우선응답 |

연 100만 원 수준은 실제 사람의 운영지원, 응답기준, 횟수, 제외업무가 명확해야 유지될 수 있다.

### 고용주 단체계약 예시

| 규모 | 권장 과금구조 |
|---|---|
| 20명 미만 | 월 최소보장 + 회원당 단가 |
| 20~99명 | 구축비 + 회원당 월 단가 |
| 100명 이상 | 기업 기본료 + 구간별 단가 + 전담 PM |

## 5. 세중과 운영사 간 권장 정산

### 옵션 1: 고정형

- 초기 구축비
- 월 고정 운영비
- 추가 작업은 사전승인 후 별도 청구

장점: 법률수임과 명확히 분리되고 예측 가능하다.

### 옵션 2: 활성회원형

- 월 기본료
- 월말 활성회원 수 × 운영단가
- P0/P1 출동 또는 현장동행 별도

장점: 회원 증가에 따라 운영인력 비용을 반영할 수 있다.

### 옵션 3: 혼합형 — 권장

- 초기 구축비
- 월 최소 운영비
- 활성회원 구간별 운영단가
- 통역·현장·야간·출장 실비
- 서비스 수준 초과분 별도

## 6. 구독 포함/제외 범위 표시

모든 상품 화면과 계약서에 아래 구분을 표시한다.

### 포함 가능

- 플랫폼 이용
- 개인정보 및 문서 보관함
- 일정·기한 알림
- 일반 절차 안내
- 정해진 횟수의 운영 상담
- 생활지원 요청 접수
- 서비스 제공내역 및 진행상태 확인

### 원칙적으로 별도

- 법률사건 착수금·성공보수
- 정부 수수료
- 행정사·노무사 수임료
- 공증·번역·아포스티유 비용
- 통신요금·보험료·숙박비·진료비
- 교통·출장·동행비
- 야간 또는 장거리 긴급출동

## 7. 청구·환불 정책 설계

- 월간 구독은 결제일 기준 다음 결제일 전일까지 제공한다.
- 연간 구독은 할인액과 중도해지 공제기준을 약관에 명시한다.
- 사용된 온보딩, 상담, 통역, 제3자 실비는 환불에서 분리한다.
- 미납 시 즉시 법률·긴급 채널을 차단하지 않고 유예기간을 설정한다.
- 고위험 사건은 구독 상태와 별도로 인권·안전 에스컬레이션 정책을 적용한다.
- 카드정보는 직접 저장하지 않고 승인된 결제대행사의 토큰을 사용한다.

## 8. 영업 문구 가이드

### 사용할 문구

- 한국 체류와 생활에 필요한 업무를 놓치지 않도록 관리합니다.
- 일정·서류·상담·생활지원 요청을 한 곳에서 확인합니다.
- 전문판단이 필요한 업무는 담당 전문가가 별도로 검토합니다.
- 처리상태와 담당자를 투명하게 확인할 수 있습니다.

### 사용하지 않을 문구

- 비자를 100% 발급합니다.
- 강제퇴거를 반드시 막아드립니다.
- 취업을 보장합니다.
- 모든 법률업무가 구독료에 포함됩니다.
- 무제한 무료 법률상담을 제공합니다.

## 9. 계약 전 반드시 확정할 항목

1. 가입비 부담주체: 근로자, 고용주, 송입운영사 중 누구인지
2. 세중이 제공하는 법률상담의 횟수와 방식
3. 운영사의 응답시간과 운영시간
4. 싱할라어·영어 통역 제공 방식
5. 현장동행 포함 여부
6. 외국인등록 및 체류민원 수행주체
7. 통신·보험·숙소 제휴 계약주체
8. 개인정보 처리자·수탁자·제3자 제공 관계
9. 환불·미납·서비스중지 기준
10. 27일 입국자 파일럿의 대상 인원과 비용
