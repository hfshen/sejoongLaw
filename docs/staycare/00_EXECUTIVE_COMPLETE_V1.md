# Sejoong StayCare 완성본 V1

## 1. 프로젝트 정의

**Sejoong StayCare**는 법무법인 세중이 서비스의 주체가 되어 외국인 근로자의 입국 전 준비, 한국 입국, 외국인등록, 체류, 고용, 숙소, 통신, 보험, 생활민원, 법률·출입국·노무 사건을 하나의 서비스로 관리하는 플랫폼이다.

이번 최초 사업 가정은 다음과 같다.

- 대상: 스리랑카 근로자 약 200명
- 7월 27일: 근로자 입국일이 아니라 200명 도입을 추진하는 담당자와의 사업협의일
- 서비스 주체: 법무법인 세중
- 플랫폼·운영 실행: 세중과 위탁계약을 체결한 운영사
- 기본 요금 기준: 1인 연 1,000,000원
- 비용 부담자: 고용주, 근로자, 도입기관·후원기관 중 계약별 선택
- 직접비 가정: 계약금액의 20~30%
- 잔여 재원: 플랫폼 개발·운영, CS, 현장관리, 품질관리와 확장에 사용

## 2. 핵심 사업원칙

### 2.1 고객에게 보이는 주체는 세중 하나다

회원과 고용주는 법무법인 세중과 서비스 계약을 체결하고 세중에 비용을 납부한다. 상담, 일반 행정, 생활지원, 법률·출입국·노무 검토는 모두 세중 통합운영센터를 통해 접수된다.

위탁 운영사, 변호사, 출입국 담당, 노무 담당, 통역, 통신·숙소·병원 수행업체는 세중 내부 업무배정 구조로 운영한다. 회원이 여러 업체와 각각 계약하고 진행상태를 추적하도록 만들지 않는다.

### 2.2 세중이 처리한다는 의미와 포함요금은 구분한다

모든 요청은 세중을 통해 처리하지만, 모든 고비용 업무가 연간 100만 원에 무제한 포함되는 것은 아니다.

연간 멤버십에는 일정관리, 상담 접수, 정기 상담, 기본 전문검토, 제한된 통역과 현장지원이 포함된다. 소송·심판·수사대응, 공식 신청대행, 장시간 통역·동행, 정부 수수료, 교통·숙박, 통신·보험·숙소·의료 실비는 세중을 통해 별도 견적·계약한다.

### 2.3 운영사는 수임료 배분이 아니라 플랫폼·운영비를 받는다

위탁 운영사의 보수는 다음 항목으로 구성한다.

- 초기 구축비
- 월 최소 운영비
- 활성회원당 운영비
- 다국어 CS·현장운영 인력비
- 플랫폼 유지보수비
- 리포트·커스터마이징 비용
- 승인된 실비

법률사건의 소개·알선 대가 또는 수임료 비율배분 형태로 설계하지 않는다.

## 3. 제품 구성

### 3.1 공개 서비스 소개

경로: `/{locale}/staycare`

- 서비스 정의
- 세중 단일 책임구조
- 연간 멤버십
- 포함·별도 서비스
- 지역·현장지원 범위
- 200명 단계별 도입
- 개인정보·권한 원칙

### 3.2 27일 담당자 브리핑

경로: `/{locale}/staycare/briefing`

- 200명 사업 정의
- 1인 연 100만 원 상품
- 인원·가격·직접비 즉석 계산
- 세중·운영사 역할
- 서비스 횟수와 SLA
- 27일 확정해야 할 10개 항목

검색엔진에는 노출하지 않는다.

### 3.3 통합 운영 플랫폼

경로: `/{locale}/staycare/demo`

- 통합 현황
- 200명 도입계획
- 회원·근로자
- 업무·기한
- 상담·사건
- 멤버십·청구
- 운영비·원가
- 리포트
- 권한·감사

현재는 합성데이터 Reference Implementation이며 실데이터 사용 전 인증, RLS, 비공개 Storage, 약관, 결제와 보안검증이 필요하다.

## 4. 200명 기준 기본 경제성

기준값:

```text
회원 수: 200명
1인 연간 멤버십: 1,000,000원
연간 계약금액: 200,000,000원
월 환산: 약 16,666,667원
직접비 20%: 40,000,000원
직접비 25%: 50,000,000원
직접비 30%: 60,000,000원
플랫폼·운영 재원: 140,000,000~160,000,000원
기준 운영 재원(25% 가정): 150,000,000원
```

위 계산은 VAT, 별도 사건 수임료, 정부 수수료와 제3자 실비를 제외한 사업설계 기준이다. 실제 계약서에서는 세금과 별도비용을 명시한다.

## 5. 완료 기준

V1 상용 준비 완료는 다음을 의미한다.

1. 세중·운영사 계약과 역할이 서면 확정되어 있다.
2. 1인 연 100만 원의 포함·제외·초과 단가가 정해져 있다.
3. 200명 명단·비자·고용주·사업장·입국파동 수집 양식이 있다.
4. 근로자 초대와 한국어·영어·싱할라어 동의가 가능하다.
5. 민감문서가 비공개 Storage와 RLS로 보호된다.
6. 모든 업무에 담당자, 기한, SLA, 증빙과 감사로그가 있다.
7. 고용주·근로자·후원기관 납부를 모두 지원한다.
8. 카드정보를 직접 저장하지 않고 승인된 PG 참조값만 관리한다.
9. 세중·운영사·고용주에게 서로 다른 리포트를 제공한다.
10. 실데이터 투입 전 보안·개인정보·운영 교육이 완료된다.
