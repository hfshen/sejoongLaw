# StayCare 서비스 카탈로그·상담·현장지원 기준

## 1. 기준 상품

### Sejoong StayCare 연간 통합관리 멤버십

- 기준금액: 1인 연 1,000,000원
- 월 환산: 약 83,333원
- 납부주체: 고용주 / 근로자 / 도입기관·후원기관
- 납부방식: 연간 일시납 / 월 분납 / 단체 일괄계약
- 서비스 창구: 법무법인 세중 통합운영센터

금액은 계약 전 세중이 최종 승인한다. VAT, 공과금, 정부 수수료, 제3자 실비와 별도 전문사건 비용은 계약서에 구분한다.

## 2. 연간 포함 서비스

### 2.1 입국 전·초기정착

- 근로자 프로필과 기본 명단 등록
- 여권·비자·경력·자격·고용정보 체크리스트
- 항공·입국파동·사업장·숙소 계획
- 외국인등록 준비상태 추적
- 유심·계좌·보험·숙소·병원 이용절차 안내
- 한국생활·안전·근로조건 다국어 가이드

### 2.2 일정·문서·알림

- 여권·비자·체류·근로계약·보험 주요기한 관리
- 120/90/60/30/14/7/3/1일 알림
- 문서 누락·반려·갱신상태 관리
- 근로자·세중·고용주별 제한된 대시보드

### 2.3 상담

- 디지털 문의: 횟수 제한 없이 접수 가능
- 예약형 비대면 상담: 연 12회
- 상담 1회 기준: 최대 30분
- 기본 전문검토: 연 4회
- 전문검토 범위: 법률·출입국·노무의 기본 쟁점과 다음 절차 안내
- 상담 결과: 담당자, 처리상태, 후속업무와 별도견적 필요 여부 기록

`무제한 접수`는 무제한 법률검토나 무제한 현장대응을 뜻하지 않는다. 중복·반복·과도한 요청은 합리적 이용정책에 따라 일정과 범위를 조정한다.

### 2.4 통역·번역

- 전화·화상 통역: 연 180분
- 우선 언어: 한국어·영어·싱할라어
- 통역시간은 실제 연결시간 기준으로 차감
- 문서 번역은 간단 안내문·운영문구 범위
- 공증·인증·전문번역은 별도 견적

### 2.5 현장지원

- 포함횟수: 연 2회
- 1회 기준: 최대 2시간
- 포함권역: 계약된 주 사업장 1개 권역 및 반경 30km
- 대상: 외국인등록·계좌·통신·보험·숙소·병원·고용주 협의 등 사전승인 업무
- 추가 사업장, 장거리, 야간, 휴일, 숙박이 필요한 업무는 별도 견적·실비

### 2.6 정기관리

- 월 1회 상태 체크인
- 위험신호 분류
- 미완료 업무·기한 임박·미응답 확인
- 고용주에게 제공 가능한 최소정보 리포트
- 세중·운영사 내부 SLA·원가·업무량 리포트

## 3. 긴급도와 SLA

### P0 — 즉시 안전·생명 위험

예시:

- 중상·의식불명·자해·폭력·감금
- 현장 안전사고와 즉시 구조가 필요한 상황

기준:

- 15분 이내 1차 확인
- 112·119 등 공공기관 우선 연결
- 세중 담당자와 고용주 비상담당 동시 통지
- 안전 확보 후 법률·노무·산재 트랙 생성

### P1 — 중대 체류·노무·법률 사안

예시:

- 체류기한 임박·취소·강제퇴거 가능성
- 임금체불·산재·폭력·형사사건
- 사업장 이탈 또는 긴급 숙소문제

기준:

- 1시간 이내 담당자 지정
- 당일 초기조치 계획
- 전문담당팀 승격

### P2 — 기한이 있는 행정·생활업무

예시:

- 외국인등록·주소변경·보험·계좌·숙소자료
- 문서반려와 기한 내 보완

기준:

- 4영업시간 이내 1차 답변
- 담당자·마감일·필요자료 지정

### P3 — 일반 문의

예시:

- 유심·교통·병원·생활정보
- 일반적인 절차·예약 문의

기준:

- 1영업일 이내 1차 답변

## 4. 별도 견적·실비

모든 요청은 세중을 통해 접수하되 다음은 연간 기본요금과 분리한다.

- 소송·심판·수사·분쟁의 법률대리
- 공식 체류·비자 신청대행과 고난도 불허대응
- 산재·임금체불 등 개별 사건 대리
- 정부 수수료·인지·공증·인증·의료·감정비
- 통신요금·보험료·숙소비·병원비·교통비
- 포함시간을 초과한 통역·번역·현장지원
- 타 지역·장거리·야간·휴일·숙박 업무

별도 업무는 세중 명의 견적 또는 적법한 수행주체 계약으로 진행한다. 회원은 플랫폼에서 견적, 승인, 결제상태와 진행상태를 확인한다.

## 5. 서비스 제공시간

- 일반 운영센터: 평일 09:00~18:00
- P0 접수: 24시간 접수 가능

- 야간·휴일 P0은 공공 긴급기관 연결과 비상연락망 통지가 우선이다.

연 100만 원의 지속가능성을 위해 다음을 적용한다.

- 동일 내용의 반복 접수 통합

- 포함시간 초과 사전안내
- 장시간 사건을 별도 업무로 전환
