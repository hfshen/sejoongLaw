# 정부·공공기관과 세중 원스톱 서비스의 업무경계

## 1. 원칙

StayCare는 정부·공공기관의 권한을 대체하지 않는다. 공식 승인·발급·선발·고용허가·출입국 결정은 해당 기관이 수행한다. 세중은 공식 절차를 이해하기 쉽게 안내하고, 필요한 자료·예약·기한·문의·결과를 플랫폼에서 통합 관리한다.

## 2. 정부·공공기관이 주도하는 영역

- 공식 모집과 송출경로
- EPS-TOPIK 등 공식 시험
- 구직자 명부와 고용허가
- 표준근로계약 관련 공식 절차
- 사전취업교육
- 사증·입국 승인과 출입국 심사
- 입국 후 취업교육과 사업장 인계
- 외국인등록·체류민원의 공식 접수·결정
- 고용허가제 보험제도와 공공지원
- 귀국지원·재정착 공공프로그램

플랫폼 제공방식:

- 공식 링크와 기관명
- 단계별 준비자료
- 사용자 입력형 상태 또는 정식 API 상태
- 예약·마감일 알림
- 보완요청과 결과 기록
- 다음 생활서비스 자동 연결

정식 API·기관협약 없이 공식 사이트를 크롤링하거나 사용자 계정으로 자동 제출하지 않는다.

## 3. 세중이 통합하는 영역

- 개인별 한국취업·생활·귀국 로드맵
- 여권·비자·계약·보험·급여 디지털 문서함
- 출입국·체류 일정과 자료 검토
- 통신·은행·송금·배송·보험·병원·숙소 서비스 신청
- 문의·민원·법률·노무 사건 접수
- 서비스 제공자 배정과 진행상태 추적
- 한국어·영어·싱할라어·타밀어 콘텐츠와 AI 언어지원
- 체류기간·여권·계약·주소·보험 만료 알림
- 귀국 준비 체크리스트

## 4. 인가·제휴 사업자가 수행하는 영역

### 통신

통신사 또는 공식 판매점이 본인확인, eSIM·SIM 개통, 요금제 가입과 해지를 수행한다. 세중은 단말호환 확인, 신청자료 전달, 수령·배송과 상태를 통합한다.

### 은행

은행이 계좌개설 심사와 금융거래를 수행한다. 세중은 필요서류, 지점·예약, 급여계좌 등록과 상태를 관리한다.

### 해외송금

은행 또는 등록된 소액해외송금업자가 KYC, 환전, 자금수취, 송금과 지급을 수행한다. 세중은 사업자 비교, 신청 연결, 진행상태와 영수증을 통합하며 자금을 직접 보유·환전·송금하지 않는다.

### 보험·의료·숙소

각 보험사·대리점·의료기관·숙소사업자가 해당 서비스를 수행한다. 세중은 신청·예약·문서·민원·결과를 연결한다.

## 5. 사용자 화면 표시기준

모든 단계에는 다음 책임표시를 붙인다.

- `정부·공공기관`: 공식 승인·처리
- `세중 원스톱`: 안내·자료·예약·추적·사건관리
- `인가·제휴 사업자`: 실제 개통·금융·송금·의료·배송
- `근로자`: 본인정보·동의·방문·결정
- `고용주`: 고용·계약·사업장·숙소·보험 관련 자료

## 6. 금지표현

- 정부 승인 또는 비자 발급 보장
- 취업 보장
- 실시간 환율·통신재고·예약을 연동 전 확정값처럼 표시
- 세중이 직접 통신·은행·해외송금 사업을 수행한다는 표현
- AI가 공식 법률·의료 통역과 판단을 대체한다는 표현
