# 한국어·영어·싱할라어·타밀어 AI 언어지원 아키텍처

## 1. 목적

AI 언어지원은 별도의 유료 통역횟수 상품이 아니라 StayCare 앱의 기본 인터페이스다.

지원기능:

- 한국어·영어·싱할라어·타밀어 텍스트 번역
- 브라우저 음성인식으로 문장 입력
- 브라우저 음성합성으로 번역결과 읽기
- 공항·사업장·병원·은행·출입국·숙소·송금 상황별 생활가이드
- 공식기관·세중·인가사업자의 역할을 구분한 다음 행동 안내

## 2. 현재 구현

API 경로:

```text
POST /api/staycare/ai
```

요청:

```json
{
  "text": "...",
  "sourceLanguage": "si",
  "targetLanguage": "ko",
  "mode": "translate",
  "context": "hospital"
}
```

지원언어:

- `ko` 한국어
- `en` 영어
- `si` 싱할라어

모드:

- `translate`: 번역문만 반환
- `guide`: 상황에 필요한 실무 다음단계를 반환

컨텍스트:

- general
- airport
- workplace
- hospital
- bank
- immigration
- housing
- remittance

## 3. 개인정보 보호

다음 형태를 AI 요청 전에 차단한다.

- 여권번호로 보이는 영문·숫자 조합
- 외국인등록번호 또는 주민등록번호 형태
- 카드번호 형태

추가 상용 요구사항:

- 계좌번호·전화번호·주소·건강정보 탐지와 사용자 재확인
- 이름·기관명 등 필요한 엔티티만 남기는 redaction
- 사용자의 AI 이용동의
- 로그와 Sentry에서 원문 제외
- `store:false`
- AI 대화 저장은 기본 비활성 또는 redacted text만 저장
- 관리자도 원문을 무제한 검색하지 못하도록 권한 분리

## 4. 안전 경계

AI가 하지 않는 일:

- 비자·체류·법률 결과 확정
- 의료 진단
- 실시간 환율·통신재고·예약 확정
- 사용자를 대신한 정부 신청
- 공식 법률·의료 통역 인증

중요한 상황은 다음으로 연결한다.

- 112 경찰
- 119 구급·소방
- 1345 출입국 종합안내
- 1350 고용노동 상담
- 1577-0071 외국인력 상담
- 세중 담당자 검토

## 5. 음성 기능

현재 UI는 브라우저 SpeechRecognition과 SpeechSynthesis를 사용한다.

제약:

- 브라우저·기기별 지원차이
- 싱할라어 음성인식 품질차이
- 시끄러운 현장과 의료·법률 용어 오류

상용 확장:

- 지원 브라우저 감지
- 텍스트 입력 fallback
- Push-to-talk
- 짧은 구간 녹음과 사용자 확인
- STT/TTS 공급자 adapter
- 언어별 WER·사용성 측정
- 긴급통화용 핵심문장 오프라인 저장

## 6. 콘텐츠 전략

AI만으로 안내하지 않고 검수된 구조화 콘텐츠를 우선 사용한다.

```text
사용자 질문
  → 의도·언어·현재 생애주기 분류
  → 검수된 StayCare 가이드와 체크리스트 검색
  → 공식기관 링크와 책임주체 결합
  → AI가 사용자의 언어로 설명
  → 필요한 신청·문의·긴급전화 버튼
```

고정 콘텐츠 우선영역:

- 공식 절차와 서류
- 긴급전화
- 체류·주소·계약 만료
- 송금 규제경계
- 통신 본인확인
- 귀국 체크리스트

## 7. 환경변수

```env
OPENAI_API_KEY=...
OPENAI_TRANSLATION_MODEL=gpt-5
```

API 키는 서버 전용이다. `NEXT_PUBLIC_` 접두사를 사용하지 않는다.

## 8. 품질검증

- 한국어↔영어↔싱할라어 생활문장 세트
- 숫자·날짜·고유명사 보존
- 병원·은행·출입국·노무 용어 검수
- 민감번호 차단
- 위험한 법률·의료 단정 방지
- 현지 싱할라어 검수자 승인
- 응답속도·비용·오류율 모니터링
