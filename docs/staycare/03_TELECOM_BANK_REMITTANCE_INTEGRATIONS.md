# 통신·은행·스리랑카 송금 연동 명세

## 1. 공통 통합구조

```text
근로자 앱
  → 서비스 신청
  → 공유할 개인정보·문서 확인과 동의
  → 세중 신청오케스트레이션
  → 인가·제휴 사업자 API 또는 담당자 포털
  → 접수·본인확인·예약·배송·처리
  → 상태·결과·영수증을 StayCare에 회신
```

플랫폼은 제휴사가 바뀌어도 같은 신청·상태 인터페이스를 유지한다. 공급자별 API는 adapter 계층으로 분리한다.

## 2. eSIM·SIM·통신

### 사용자 흐름

1. 휴대폰 모델 입력
2. eSIM 지원 여부와 통신사 잠금 확인
3. 여권·입국일·공항·항공편 확인
4. 방식 선택
   - 온라인 eSIM QR
   - 공항 카운터 수령
   - 담당자 일괄수령
   - 숙소 배송
5. 신청에 사용할 개인정보 확인·동의
6. 통신사·공식 판매점 본인확인
7. 주문·배송·수령·활성화 상태
8. 한국 전화번호를 프로필에 연결
9. 외국인등록 후 장기요금제 전환
10. 귀국 전 해지·번호·자동이체 정리

### 저장 데이터

- SIM 유형
- 단말모델
- IMEI 일부 마스킹값
- eSIM 호환 여부
- 본인확인 방식
- 도착공항·터미널
- 수령·배송방식
- 배송지 요약
- 주문·배송·활성화 참조번호
- 한국 전화번호
- 해지요청 상태

### 연동 전 표시

- 실제 요금제 가격·재고·개통가능 여부를 확정값으로 표시하지 않음
- `제휴 통신사 연결 필요` 상태
- 신청은 임시접수로만 저장

## 3. 은행·급여계좌

### 사용자 흐름

1. 외국인등록 상태 확인
2. 여권·등록·근로계약·한국 전화번호 점검
3. 이용 가능한 은행·지점 안내
4. 방문예약 또는 고용주 일괄 일정
5. 계좌개설 심사
6. 체크카드·모바일뱅킹·인증수단
7. 급여계좌 등록
8. 통신·보험·숙소 자동이체
9. 귀국 전 잔액·자동이체·계좌정리

은행의 계좌개설 심사결과를 세중이 보장하지 않는다.

## 4. 스리랑카 해외송금

### 규제 원칙

- 실제 자금수취·환전·송금은 은행 또는 등록된 소액해외송금업자가 수행
- StayCare는 자금을 직접 보유하지 않음
- StayCare는 환전 또는 송금의 계약당사자로 표시하지 않음
- 정식 제휴·API 계약 전에는 실시간 견적을 표시하지 않음

### 사용자 흐름

1. 급여계좌와 본인확인 상태
2. 스리랑카 수취인 이름·관계
3. 수취은행·지점·계좌
4. 송금목적
5. 복수 인가사업자의 견적 요청
6. 비교항목
   - 적용환율
   - 수수료
   - 예상 수취 LKR
   - 예상 도착시간
   - 수취방식
7. 근로자가 사업자 선택
8. 선택 사업자의 KYC·거래확인
9. 송금 실행
10. 처리중·지급완료·실패·취소·환불 상태
11. 송금번호와 영수증 보관

### 데이터 최소화

- 수취계좌는 플랫폼 목록에서 마스킹
- 사업자가 발급한 토큰 또는 외부 참조값 우선 저장
- 송금금액과 영수증은 근로자·세중 권한자만 접근
- 고용주는 개인 송금내역을 열람하지 못함

## 5. 공항·숙소 배송

배송대상 예시:

- 물리 SIM
- 교통카드
- 한국생활 안내키트
- 제휴사가 적법하게 제공하는 기타 물품

배송방식:

- 공항 카운터 개별수령
- 항공편별 일괄 인계
- 교육기관 일괄 인계
- 숙소 호실별 배송

필수상태:

- 예약
- 준비중
- 수령가능
- 출고
- 배송중
- 전달완료
- 활성화완료
- 실패·재배송

## 6. 공급자 Adapter 인터페이스

모든 공급자 adapter는 다음 기능 중 지원범위를 선언한다.

```text
createApplication
verifyIdentity
getQuote
confirmOrder
schedulePickup
createDelivery
getStatus
downloadReceipt
cancel
requestRefund
terminateService
```

공통 요구사항:

- OAuth2, API key, mTLS 또는 서명 웹훅
- 멱등키
- 재시도와 중복방지
- 외부 참조번호
- 사용자에게 표시할 상태와 내부 원상태 분리
- 개인정보 처리·위탁·보존 계약버전
- 장애 시 수동처리 전환
