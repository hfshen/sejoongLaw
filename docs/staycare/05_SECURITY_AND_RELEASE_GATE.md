# 개인정보·보안·상용 전환 게이트

## 1. 고위험 데이터

- 여권과 비자 원문
- 외국인등록정보
- 고용계약·임금·근로시간
- 숙소·연락처·비상연락망
- 보험·산재·병원·건강정보
- 법률·노무·형사·인권상담
- 은행·수취인·송금금액·영수증
- 통신신청과 IMEI 일부
- 출입국 신청·결정

## 2. 저장 원칙

- 원본 문서는 Supabase private Storage
- 공개 URL 금지
- 짧은 만료 Signed URL
- 목록에는 번호 전체를 표시하지 않음
- 여권·등록·계좌·IMEI 마스킹
- 파일 유형·크기·악성파일 검사
- 업로더·검수자·버전·해시·보존기간
- 조회·다운로드·공유·내보내기 감사로그

## 3. 동의

서비스마다 공유할 항목과 수신자를 다시 확인한다.

- 이용약관
- 개인정보 수집·이용
- 민감정보
- 제3자 제공
- 업무위탁
- 국외이전
- AI 이용
- 마케팅 선택동의

근로자 동의 없이 고용주·현지기관·제휴사에 자료를 포괄 제공하지 않는다.

## 4. 권한

- 세중 관리자
- 세중 변호사·출입국 담당
- 운영 PM·코디네이터
- 고용주 담당
- 현지 교육·송출기관 담당
- 공급자 담당
- 근로자 본인
- 감사자

RLS는 테넌트·조직·근로자·배정업무를 기준으로 적용한다.

고용주·현지기관에 기본 비공개:

- 개인 법률상담
- 건강·의료 상세
- 형사·가정·인권상담
- 개인 송금내역과 수취인
- 고용주와 이해상충이 있는 노무상담

공급자는 배정된 신청과 필요한 최소자료만 접근한다.

## 5. 공급자 연동

- 자격·사업등록·제휴계약 확인
- API 키·OAuth token·웹훅 secret은 비밀저장소
- 로그에 credential·개인정보 금지
- 웹훅 서명검증과 멱등성
- 공급자 장애 시 수동처리 전환
- 계약 종료 시 계정·토큰 회수
- 공급자 개인정보 삭제확인

## 6. 해외송금

- StayCare가 자금을 보유·환전·송금하지 않음
- 등록된 사업자 연결
- 계좌목록 마스킹
- 공급자 token 또는 외부참조값 우선
- 실시간 견적은 정식 API 데이터만 표시
- 근로자 최종확인 후 거래
- 고용주 접근 차단

## 7. AI

- 서버 전용 API 키
- `store:false`
- 여권·등록·카드번호 사전차단
- 원문 로그 금지
- redacted content만 선택적 저장
- AI 사용동의
- 법률·의료·출입국 중요판단은 사람에게 승격

- [ ] RLS 자동테스트와 타조직 침투테스트

- [ ] 공급자 Sandbox와 웹훅 테스트
- [ ] AI 민감정보 차단·품질검수
- [ ] 알림 SMS·이메일·Push

## 9. 현재 상태

현재 공개 페이지와 근로자 앱은 합성데이터 Reference Implementation이다. 실제 개통, 은행계좌, 해외송금, 정부신청은 연동되지 않았다. 화면에서 제출되는 신청은 제휴연동 전까지 임시접수로만 표시해야 한다.
