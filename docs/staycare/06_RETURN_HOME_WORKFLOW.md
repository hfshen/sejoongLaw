# 귀국 원스톱 워크플로

## 1. 시작시점

귀국예정일 D-180부터 개인별 귀국계획을 생성한다. 갑작스러운 계약종료·중도귀국·강제출국 등은 별도 긴급 플로우로 전환한다.

## 2. D-180~D-120

- 귀국예정일과 계약종료일 확인
- 체류기간과 여권 유효기간
- 최종근무·휴가·항공 계획
- 출국만기보험·귀국비용보험 등 적용항목
- 퇴직금과 예상 최종급여
- 미지급 임금·산재·분쟁 여부
- 스리랑카 수취계좌와 최종송금 준비

## 3. D-90~D-60

- 보험금 청구자료
- 퇴직금·최종급여 계산자료
- 은행계좌·자동이체 목록
- 통신·인터넷 계약과 해지조건
- 숙소퇴실·보증금·공과금
- 소지품·수하물·배송
- 출국·귀국 후 필요한 증명서

## 4. D-30~D-7

- 최종급여·퇴직금·보험금 진행상태
- 본국 최종송금 견적과 수취인 확인
- 통신 해지 또는 출국일까지 유지
- 계좌잔액과 자동이체 정리
- 숙소점검·열쇠·보증금
- 항공편·공항이동
- 외국인등록 관련 출국 안내
- 고용주 인계·종료확인

## 5. 출국일

- 공항이동과 항공편
- 필요한 원본서류
- 통신·긴급연락수단
- 미완료 보험·급여·송금 건의 한국 담당자
- 스리랑카 도착 후 연락채널

## 6. 출국 후

- 최종송금 수취확인
- 보험금·퇴직금·환급금 후속상태
- 한국 계좌의 잔여 거래 확인
- 발급받지 못한 증명·경력자료
- 본국 재정착·교육·취업지원 연결
- 개인정보 보존·파기 일정 안내

## 7. 플랫폼 상태

```text
not_started
planning
in_progress
ready
completed
cancelled
```

체크항목:

- final_salary_status
- severance_status
- insurance_claim_status
- final_remittance_status
- bank_closure_status
- telecom_closure_status
- accommodation_checkout_status
- departure_record_status
- reintegration_status

## 8. 책임구분

- 정부·공공기관: 보험·출국·귀국지원의 공식 처리
- 고용주: 계약종료·급여·퇴직·숙소·인계자료
- 세중: 자료·마감·사건·상태·후속관리
- 은행·송금업자·통신사: 실제 금융·통신 처리
- 근로자: 최종확인·동의·방문·수취인과 연락수단 유지

## 9. 완료조건

귀국완료는 비행기 탑승만을 의미하지 않는다. 다음 항목이 완료되거나 후속담당자가 지정돼야 한다.

- 미지급 임금·퇴직·보험
- 최종송금과 수취확인
- 계좌·통신·숙소 종료
- 필요한 증명서
- 귀국 후 연락수단
- 후속사건 담당자
- 개인정보 보존·파기 안내
