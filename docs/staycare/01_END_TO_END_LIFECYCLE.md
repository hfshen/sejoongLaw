# 스리랑카 근로자 한국취업·생활·귀국 생애주기

## 1. 스리랑카 현지 준비

### 공식 모집·등록

- 정부 또는 지정 송출·교육기관의 모집공고 확인
- 여권과 개인 신원정보 등록
- 지원 가능한 업종·직종과 결격사유 확인
- 공식 비용과 영수증 확인

### 시험·교육·자격

- EPS-TOPIK 등 적용 시험
- 기능평가·경력·자격자료
- 건강검진
- 사전취업교육

플랫폼 역할:

- 공식기관 링크와 일정 제공
- 본인의 시험·교육·자료 준비상태 표시
- 여권·경력·자격자료의 디지털 문서함
- 정부처리 상태와 민간 준비항목 연결

## 2. 정부·EPS 공식 절차

적용 자격과 제도에 따라 다음 단계가 공식기관을 통해 진행된다.

- 구직자 명부 등록
- 고용주 선택과 고용허가
- 표준근로계약 체결
- 사증·입국 관련 절차
- 항공·입국 일정
- 입국 후 취업교육과 사업장 인계
- 고용허가제 전용보험·지원서비스

플랫폼은 승인 또는 발급을 보장하지 않는다. 공식기관의 결과, 필요한 문서, 다음 행동과 마감일을 기록한다.

## 3. 비자 발급 후 출국 전

### 디지털 프로필

한 번 입력하는 정보:

- 영문명·생년월일·국적
- 여권과 비자
- 고용주·사업장·직무
- 항공편·도착공항·터미널
- 숙소·비상연락처
- 선호언어

### 통신 사전신청

- 휴대폰 모델과 eSIM 지원 확인
- IMEI 또는 단말호환 확인
- eSIM QR 온라인 발급 가능 여부
- 물리 SIM 공항수령 또는 숙소배송
- 도착 직후 사용할 선불서비스
- 외국인등록 후 장기요금제 전환 계획

### 입국·이동 준비

- 공항 집결장소와 담당자
- 교육기관·사업장·숙소 이동
- 교통카드와 초기 생활키트
- 한국 긴급전화와 세중 연락채널

## 4. 한국 도착

- 공항 도착 확인
- eSIM 설치 또는 SIM 수령·활성화
- 공식 인계와 취업교육 상태
- 숙소 체크인
- 본인·고용주·세중 연락망 활성화
- 초기 안전·생활 안내

## 5. 초기 정착 90일

### 외국인등록

- 관할기관과 예약
- 여권·비자·사진
- 고용·체류지 입증자료
- 접수·보완·발급상태

### 통신

- 본인명의 장기요금제
- 번호 유지·변경
- 자동이체
- 해지·위약·단말조건 안내

### 금융

- 급여계좌 개설 준비
- 은행지점·예약
- 체크카드
- 급여계좌 등록
- 자동이체와 인증수단

### 보험

- 고용허가제 관련 보험
- 적용 가능한 사회보험
- 보험가입 상태와 보험금 청구정보

### 숙소·생활기반

- 주소와 방 배정
- 숙소비·공제·생활규칙
- 시설 이상·보증금·공과금
- 병원·약국·교통·쓰레기·생활정보

## 6. 한국 생활·근로

### 급여와 근로

- 근로계약서
- 월별 급여명세
- 실제 입금액
- 공제·숙소비·연장근로
- 임금·산재·사업장 문제 접수

### 스리랑카 송금

- 본인확인과 급여계좌
- 스리랑카 수취인·은행·계좌
- 인가된 사업자의 환율·수수료·예상 LKR·소요시간 비교
- 선택한 사업자 화면 또는 API에서 송금 실행
- 송금번호·수취확인·영수증·실패·환불상태

세중 플랫폼은 자금을 직접 보유하거나 환전·송금하지 않는다.

### 의료·건강

- 증상별 진료과 안내
- 외국어 가능 의료기관
- 예약과 필요한 문장
- 보험적용·본인부담 안내
- 산재 또는 긴급상황 분류

### AI 언어지원

- 한국어·영어·싱할라어 텍스트 번역
- 브라우저 음성입력·음성출력
- 공항·사업장·병원·은행·출입국·숙소·송금 상황별 가이드
- 여권번호·등록번호·카드번호 입력 차단
- 법률·의료 중요결정은 담당자 확인

## 7. 체류 연장·변경

- 체류기간 만료 120일 전 사전점검
- 여권만료
- 근로계약 갱신
- 체류지 변경신고
- 사업장 변경 가능사유와 기한 검토
- 체류자격 변경 가능성
- 예약·신청·보완·결과 추적

## 8. 귀국 준비

D-180부터 다음을 시작한다.

- 귀국예정일과 계약종료일
- 최종급여와 미지급금
- 퇴직금 또는 차액
- 출국만기보험·귀국비용보험 등 적용 항목
- 최종 본국송금
- 은행잔액·자동이체·계좌 정리
- 휴대폰·인터넷 해지
- 숙소퇴실·보증금·공과금
- 외국인등록증·출국서류
- 항공·수하물
- 귀국 후 재정착·취업정보

## 9. 공통 데이터 원칙

- 동일 자료는 한 번 저장
- 서비스별 최소필요 정보만 공유
- 공유 전 수신자·목적·항목을 표시
- 공식기관 상태와 민간서비스 상태를 분리
- 모든 마감일과 완료증빙 보관
- 개인정보·법률·의료·송금자료는 고용주에 기본 비공개
