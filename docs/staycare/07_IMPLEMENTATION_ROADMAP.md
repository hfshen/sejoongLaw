# StayCare 구현 로드맵

## Phase 0 — Reference Application

현재 브랜치 구현 범위:

- 공개 제품 소개
- 한국어·영어·싱할라어·타밀어 근로자 앱
- 8단계 생애주기
- 정부절차·세중·인가사업자 책임표시
- eSIM·SIM·공항수령·숙소배송 신청 UI
- 외국인등록·체류행정 신청 UI
- 급여계좌·스리랑카 송금 흐름
- AI 번역·생활가이드 API와 브라우저 음성
- 디지털 문서함 UI
- 긴급전화
- 귀국 워크플로
- Supabase 테넌트·RLS·서비스·공급자 데이터모델

합성데이터와 임시접수만 사용한다.

- Supabase Auth
- 이메일·휴대폰 또는 기관초대 가입
- 한국어·영어·싱할라어·타밀어 약관
- 개인정보·민감정보·AI·제3자 제공 동의
- private Storage
- 여권·비자·계약 업로드와 검수
- 근로자별 생애주기 인스턴스 생성
- 공식단계 수동상태 입력

## Phase 2 — 알림·출입국·운영

- 마감일 엔진
- 체류·여권·계약·주소 알림
- 외국인등록·주소변경·연장 사건관리
- 세중 운영자 큐
- 고용주 제한 포털
- 현지 교육·송출기관 제한 포털
- 한국어·영어·싱할라어·타밀어 알림

## Phase 3 — 통신·배송

- 통신사·공식 판매점 선정
- 단말 호환 API 또는 규칙엔진
- eSIM·SIM 신청
- 공항수령 슬롯
- 항공편별 일괄 인계
- 숙소배송·배송조회
- 활성화와 한국 전화번호 연결
- 외국인등록 후 장기요금제 전환
- 귀국 전 해지

## Phase 4 — 은행·송금

- 제휴 은행 또는 외국인 금융지원 채널

- 송금상태·영수증·실패·환불

## Phase 5 — AI·콘텐츠

- 구조화된 공식·생활 콘텐츠 검색

- 병원·은행·출입국·노무 품질셋

- D-180 귀국계획 자동생성

## 출시 게이트

각 Phase는 다음 조건을 만족한 뒤 Production에 적용한다.

- 계약과 법적 수행주체 확인
- 개인정보 영향검토
- RLS·Storage·API 보안테스트
- 공급자 Sandbox
- 다국어 검수
- 장애·수동처리 fallback
- 실제 사용자 제한 베타
- 운영자 교육과 승인
