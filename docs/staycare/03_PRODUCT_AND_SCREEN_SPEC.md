# StayCare 제품·화면·권한 명세 V1

## 1. 사용자 역할

| 역할 | 설명 | 주요 권한 |
|---|---|---|
| sejoong_admin | 세중 서비스 관리자 | 상품·계약·조직·회원·청구·권한·리포트 전체 |
| sejoong_lawyer | 세중 담당 변호사 | 법률·출입국 전문티켓, 필요한 문서, 의견·결과 |
| operator_manager | 위탁 운영 PM | 회원·업무·SLA·원가·운영인력·리포트 |
| operator_agent | 운영 코디네이터 | 온보딩·일정·일반문의·현장지원·증빙 |
| employer_admin | 고용주 담당 | 소속 회원의 최소필요 현황·자료요청·일정 |
| specialist | 세중 지정 수행팀 | 배정된 업무와 최소필요 자료만 접근 |
| worker | 근로자 회원 | 본인 문서·일정·문의·구독·동의 |
| auditor | 감사 | 감사로그·권한·내보내기 기록 읽기 |

고객에게는 세중이 단일 창구로 표시한다. 위탁 운영사와 지정 수행팀은 내부 담당조직 또는 세중 지정 수행팀으로 표현한다.

## 2. 공개 서비스 페이지

경로: `/{locale}/staycare`

### 화면 목적

- 서비스의 법적·운영적 주체가 세중임을 설명
- 200명 도입 관리역량 설명
- 연 100만 원의 포함·별도 범위 표시
- 고객이 여러 업체를 직접 관리하지 않는 구조 설명
- 플랫폼과 브리핑 화면 연결

### 필수 블록

1. Hero
2. 입국 전~연간관리 생애주기
3. 세중·위탁 운영사·수행팀 구조
4. 연간 멤버십
5. 지역·현장지원
6. 별도 견적·실비
7. 단계별 도입
8. 개인정보·권한

## 3. 담당자 브리핑

경로: `/{locale}/staycare/briefing`

검색엔진 비노출.

### 화면 목적

- 7월 27일 방문 담당자에게 사업을 한 번에 설명
- 200명, 1인 연 100만 원, 직접비 20~30% 계산
- 담당자가 인원·가격·비용부담자를 바꿔 시뮬레이션
- 계약 전 확인사항을 회의 의제로 사용

### 기능

- 인원 20~1,000명 조정
- 연간 요금 300,000~2,000,000원 조정
- 직접비 20~30% 조정
- 고용주·근로자·후원기관 납부자 선택
- 연 매출·월 환산·직접비·운영재원 계산
- 27일 확정사항 10개 표시
