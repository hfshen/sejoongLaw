# StayCare 200명 사업·수익·운영비 모델

## 1. 기본 계약가정

| 항목 | 기준안 |
|---|---:|
| 관리회원 | 200명 |
| 1인 연간 멤버십 | 1,000,000원 |
| 연간 계약금액 | 200,000,000원 |
| 월 환산 매출 | 약 16,666,667원 |
| 직접비 목표 | 20~30% |
| 플랫폼·운영재원 | 70~80% |

금액은 VAT 별도 기준 예시다. 실제 계약에서 VAT 포함 여부, 선수금, 분납, 환불, 중도 입·퇴사 정산방식을 확정한다.

## 2. 직접비 시나리오

| 직접비율 | 연간 직접비 | 플랫폼·운영재원 | 1인 운영재원 |
|---:|---:|---:|---:|
| 20% | 40,000,000원 | 160,000,000원 | 800,000원 |
| 25% | 50,000,000원 | 150,000,000원 | 750,000원 |
| 30% | 60,000,000원 | 140,000,000원 | 700,000원 |

직접비에는 전문가 수행비, 통역·번역, 승인된 현장 교통, 제3자 업무처리와 예외비용을 포함한다. 별도 사건과 제3자 상품대금은 기본 멤버십 원가에 억지로 포함하지 않는다.

## 3. 25% 직접비 예시

| 직접비 항목 | 비율 | 연간 예산 |
|---|---:|---:|
| 법률·출입국·노무 기본수행 | 10% | 20,000,000원 |
| 싱할라어·영어 통역·번역 | 5% | 10,000,000원 |
| 현장지원·교통·지역 수행 | 5% | 10,000,000원 |
| 통신·숙소·의료 등 실행비 | 3% | 6,000,000원 |
| 긴급·예외 직접비 예비 | 2% | 4,000,000원 |
| 합계 | 25% | 50,000,000원 |

실제 업무량이 기준을 넘으면 포함량을 조정하거나 별도 견적을 적용한다.

## 4. 플랫폼·운영재원 75% 예시

| 운영 항목 | 비율 | 연간 예산 |
|---|---:|---:|
| 플랫폼 개발·보안·유지보수 | 15% | 30,000,000원 |
| 위탁 운영 PM·코디네이터·CS | 30% | 60,000,000원 |
| 세중 통합운영·품질관리 | 15% | 30,000,000원 |
| 다국어 콘텐츠·교육·리포트 | 5% | 10,000,000원 |
| 사업관리·예비비·확장재원 | 10% | 20,000,000원 |
| 합계 | 75% | 150,000,000원 |

위 배분은 협상용 기준안이다. 세중과 위탁 운영사의 실제 보수는 `플랫폼 구축비 + 월 최소운영비 + 활성회원당 운영비 + 승인실비`로 계약한다.

## 5. 위탁 운영사 보수 구조

권장 계약식:

```text
초기 구축비
+ 월 기본 운영비
+ 활성회원당 월 운영단가
+ 다국어·현장 전담인력비
+ 승인된 실비
+ 별도 개발·리포트·연동비
```

### 초기 구축비

포함 범위:

- 세중 StayCare 별도 앱 구축
- 테넌트·권한·데이터베이스
- 200명 명단 업로드와 온보딩
- 한국어·영어·싱할라어 기본 화면
- 업무·SLA·티켓·구독·리포트
- Vercel·Supabase 배포기반

### 월 기본 운영비

포함 범위:

- 운영 PM
- 시스템 관리
- 업무배정·SLA 모니터링
- 세중·도입기관·고용주 정기회의
- 월간 경영·운영 리포트

### 활성회원당 운영단가

포함 범위:

- 회원·문서·일정 관리
- 문의 티켓 운영
- 월간 체크인
- 알림·리포트·데이터 유지

운영사의 보수는 법률사건 수임료의 일정 비율이 아니라 소프트웨어·운영서비스의 대가로 책정한다.

## 6. 비용부담자별 계약

### 고용주 부담

- 고용주와 세중이 단체계약
- 근로자는 무료로 앱 사용
- 고용주에는 소속인력의 최소필요 정보만 제공
- 개인 법률·건강·민원 원문은 기본 비공개

### 근로자 부담

- 근로자 개인이 세중과 멤버십 계약
- 모국어 약관·환불·자동결제 동의 필요
- 고용과 비자결과를 보장하는 상품으로 표현 금지
- 임금에서 강제 공제하지 않음

### 도입기관·후원기관 부담

- 송출·도입·지원기관이 단체 비용 부담
- 실제 근로자에게 비용이 전가되는지 공개
- 기관이 회원의 민감상담 내용을 열람할 수 없도록 제한

## 7. 청구·환불 원칙

- 월·연 결제를 모두 지원하되 기준 계약은 연간 멤버십
- 카드번호·CVC 직접 저장 금지
- 승인된 PG의 고객·구독·결제 참조값만 저장
- 웹훅 서명과 멱등성 검증
- 계약시작 전 취소, 중도 입국취소, 귀국·퇴사·사망 등 환불정책 명시
- 이미 제공된 온보딩·상담·현장지원 비용 공제기준 명시
- 고위험 안전채널은 미납만으로 즉시 차단하지 않음

## 8. 손익을 지키는 운영장치

- 예약상담 연 12회, 기본 전문검토 연 4회
- 통역 연 180분, 현장지원 연 2회
- 계약 사업장 1개 권역 기준
- 초과업무 사전승인·별도견적
- 업무시간·이동시간·외부비용 기록
- 회원별 원가와 고비용 유형 대시보드
- 50명 단위로 운영인력 수요 재산정
- 월별 직접비율이 30%를 넘으면 가격·포함량·프로세스 조정
